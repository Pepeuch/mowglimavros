# Historical tools — DO NOT RUN on the robot

Twelve ancillary artifacts recovered from local Oct9 build/deployment/audit
files. They are NOT part of the47-file stash and are retained for provenance,
not installed, invoked, or silently promoted to current operational tooling.
Hashes and the original package archive are inventoried separately.

Several scripts send ARM/servo commands or recreate a sidecar; others depend
on private rollback paths, expired image baselines and old acquisition rates.
They are historical procedures, not safe current entry points. No saved .env,
passwords, private rollback configuration or ARM64 executable is imported.
Any reuse requires fresh authorization, guards, independent rescue and review.
Only shell syntax/Python AST are validated in the recovery task.
